# 后端基础框架

## 项目结构

### 整体结构
```
│ backend/                                                      # 后端根目录
│   ├── lawyer-common/                                          # 通用模块
│   ├── lawyer-spring-demo1/                                    # Spring演示项目2
│   ├── lawyer-spring-demo2/                                    # Spring演示项目3
│   └── pom.xml                                                 # 父POM
│   └── .../                                                    # 其他业务模块
│
docs/                                                           # 项目文档
├── requirement/                                                # 需求文档
├── design/                                                     # 详细设计文档
├── api/                                                        # API设计文档
└── architecture/                                               # 架构设计文档
```

## Spring演示项目1

### 模块名
lawyer-spring-demo1

### 功能定位
- 演示Spring Boot的基本配置和使用
- 展示如何集成Spring Web进行RESTful API开发
- 展示基于虚拟线程的WEB请求处理
- 对比传统线程和虚拟线程的性能差异，通过基准测试展示虚拟线程的优势
- 展示如何集成Spring Security进行权限管理
- 演示如何使用Spring Data JPA进行数据库操作
- 展示如何使用OpenTelemetry进行性能监控
- 展示如何使用Prometheus和Grafana进行监控和可视化

### 依赖
- SpringBoot
- spring-boot-starter-web
- spring-boot-starter-opentelemetry
- spring-boot-starter-security
- spring-boot-starter-data-jpa
- lawyer-common

### 参考资料
- [Spring OpenTelemetry](https://opentelemetry.io/docs/zero-code/java/spring-boot-starter/)

### 限制
- 仅提供演示功能，不允许被其他模块引用
