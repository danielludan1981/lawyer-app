# 后端爬虫解析器实现

## 抽象DataParser实现类，AbstractDataParser
1. 定义AbstractDataParser抽象类，实现DataParser接口，包含默认的getName方法，返回解析器的类名。
2. protected方法getUrlPrefix，用于返回解析器支持的URL前缀，默认返回null。
3. 定义默认的supports方法，逻辑如下
    - 从metadata中获取url字段
    - 调用getUrlPrefix方法获取解析器支持的URL前缀, 如果返回不为null则判断url是否以前缀开头。这里的匹配忽略http和https。只要url包含前缀即可。
    - 返回判断结果
4. 定义两个抽象解析方法，子类需实现
    - abstract Object parseMap(Map<String, Object> data, Map<String, Object> metadata)：根据基础数据data和metadata，进行解析并返回处理后的结果。
    - abstract List<Map<String, Object>> parseList(List<Map<String, Object>> data, Map<String, Object> metadata)：根据基础数据data和metadata，进行解析并返回处理后的结果。
4. 定义默认的parse方法，逻辑如下
    - 如果data为null，打印warn日志，返回null
    - 否则，根据data的类型进行解析
        - 如果data是String类型，表示返回的是整个html，直接返回data
        - 如果data是Map类型，转型为Map<String, Object>, 调用parseMap(Map<String, Object> data, Map<String, Object> metadata)方法
        - 如果data是List类型，转型为List<Map<String, Object>>, 调用parseList(List<Map<String, Object>> data, Map<String, Object> metadata)方法
        - 其他类型，打印warn日志，返回null

    - 获取metadata中的url字段，作为baseUrl
    - 遍历List中的每个元素
    - 每个元素解析并映射到ArticleDTO对象，映射规则如下
        - 获取href字段的值，解析为Element对象。该Element对象的Html表示和映射关系如下
            - 示范：<a href=\"../c30834/202601/t20260108_451070.html\" target=\"_blank\">全国人民代表大会常务委员会预算工作委员会、全国人民代表大会财政经济委员会、全国人民代表大会教育科学文化卫生委员会关于财政高等教育资金分配和使用情况的调研报告</a>
            - 从Element对象中提取text值，作为ArticleDTO的title字段, 注意trim()去掉首尾空格
            - 从Element对象中提取href字段的值，根据baseUrl和href字段的值（该值为相对url路径），拼接成完整的url，作为ArticleDTO的url字段

            - 示范：<span>2026-01-08</span>
            - 从Element对象中提取text值，作为ArticleDTO的publishedAt字段, 注意trim()去掉首尾空格
            - 如publishedAt无法解析为日期格式，则设置为null，打印日志且，该元素不加入到最终返回的列表中
        - 将合法的ArticleDTO对象添加到一个新的列表中返回
