# 后端爬虫增加DataParser实现

## 具体解析器实现类

### 名称**国务院国资委官网-互动交流**
1. 定义SasacGovCommunicationDataParserImpl，实现AbstractDataParser抽象类。
2. 支持的URL前缀为http://www.sasac.gov.cn/hdjl_index.html
3. 实现parseMap方法，直接抛出UnsupportedOperationException异常
4. 实现parseList方法，逻辑如下
    - 获取metadata中的url字段，作为baseUrl
    - 遍历List中的每个元素
    - 每个元素解析并映射到ArticleDTO对象，映射规则如下
        - 获取href字段的值，解析为Element对象。该Element对象的Html表示和映射关系如下
            - 示范：<a href=\"n2588040/n2590387/n9854167/c35249072/content.html\" target=\"blank\">关于股权回购及合伙企业份额回购问题的咨询</a>
            - 从Element对象中提取text值，作为ArticleDTO的title字段, 注意trim()去掉首尾空格
            - 从Element对象中提取href字段的值，根据baseUrl和href字段的值（该值为相对url路径），拼接成完整的url，作为ArticleDTO的url字段
        - 获取publishedAt字段的值，解析为Element对象。该Element对象的Html表示和映射关系如下
            - 示范：<span>[12-29]</span>
            - 从Element对象中提取text值，去除无意义的方括号，作为ArticleDTO的publishedAt字段, 注意trim()去掉首尾空格;解析方式为年部分统一为当年，拼接提取的月和日，格式为yyyy-MM-dd，如果最终日期大于今天则将年改为今年减去1年，否则不变
            - 如publishedAt无法解析为日期格式，则设置为null，打印日志且，该元素不加入到最终返回的列表中
        - 将合法的ArticleDTO对象添加到一个新的列表中返回
