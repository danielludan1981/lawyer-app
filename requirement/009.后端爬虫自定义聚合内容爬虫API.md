# 后端自定义聚合内容爬虫API

## 目标
1. 提供自定义的聚合内容爬虫API，能够让用户使用简单的请求参数启动自定义的聚合任务

## API接口
创建CrawlCustomController, 前缀URL为/api/crawler/custom
1. 创建聚合任务（POST /aggregationTasks/govArticles）
   - 请求体：publishedInDays - 爬取的发布时间范围（单位：天）
   - 响应体：DataResponseAggregateDTO

## 服务层
增加service/facade/CrawlCustomFacade, 负责处理自定义聚合任务的业务逻辑

### 方法 **createGovArticlesAggregationTask(int publishedInDays)**
描述：创建一个聚合任务，用于爬取国家法律网站的法规文章
- 参数：publishedInDays - 爬取的发布时间范围（单位：天）
- 返回值：DataResponseAggregateDTO
- 逻辑：使用CrawlAggregationFacade创建一个聚合任务，创建时组装的请求报文参考“聚合任务爬虫请求.http”中的创建聚合法规内容爬虫任务，其中每个CrawlRequestDTO中以下参数替换为用户请求的publishedInDays参数值,其余参数保持不变：
  "metadata": {
      "publishedInDays": publishedInDays
   }
